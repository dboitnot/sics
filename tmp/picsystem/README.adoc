== Building

The master document is `index.adoc`.
Build with any AsciiDoc-compliant toolchain.

=== HTML

[source,bash]
----
asciidoctor index.adoc
----

=== PDF

[source,bash]
----
asciidoctor-pdf index.adoc
----

=== EPUB

[source,bash]
----
asciidoctor-epub3 index.adoc
----

=== Single-file output

To produce a single self-contained HTML file:

[source,bash]
----
asciidoctor -a data-uri index.adoc
----

== Editing individual categories

Each category file is self-contained and can be edited independently.
The master `index.adoc` uses `include::` directives with `leveloffset=+1` so that each category's top-level `==` becomes a `===` subsection under the master "Category sections" heading.

To add a new category:

. Create a new file in `categories/` following the same structure as existing categories (top-level `==` heading).
. Add an `include::` directive in `index.adoc` in the appropriate position.
